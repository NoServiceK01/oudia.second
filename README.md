# oud2 列車位置表示

OuDiaSecond の `.oud2` ダイヤファイルを読み込んで、時刻表に基づく列車の位置(在線)を路線図の上に表示する、ブラウザだけで動く静的ページです。ファイルはブラウザ内で読み込むだけで、外部には送信されません。

## 使い方

1. `index.html` をブラウザで開く(またはGitHub Pagesで公開する)
2. `.oud2` ファイルをドロップするか、右上の「開く」で選ぶ
3. ダイヤ、時刻、速度を選ぶ。列車や駅をタップすると詳細が出る

## 主な機能

- ダイヤの切り替え、時刻の直接入力、再生・停止、×1 / ×10 / ×30 / ×60 / ×300 倍速、「いま」で現在時刻へ
- 列車種別の名前と色をファイルから読み取って表示。列車アイコンに種別の頭文字を表示
- 分岐線を右隣のレーンに表示。合流する分岐は駅の上側、分かれる分岐は下側に伸ばし、駅間でカーブして本線につなぐ
- 駅間を4分割して段階的に進める。分岐では2/4を過ぎたところで分岐先へ移る
- 同じ駅・同じ方向に複数の列車がいるときだけ、外側へ寄って重ならないようにする
- 上りは線の左側、下りは右側に表示。近い列車は「+n」にまとめる
- 列車をタップ: 各駅の着発時刻と現在位置。駅をタップ: 方面を選んで時刻表を表示(分の下に行先)
- 各駅に停車する種別を駅名の下に表示
- 設定(⚙): 路線の色、種別ごとの表示(在線 / 時刻表)。ライト / ダークの切り替え(初期はライト)
- 駅名の長さに合わせて幅を調整し、広い路線は横スクロール

## oud2 の読み取りについて

- 文字コードは UTF-8(失敗したら Shift_JIS)
- 上り列車の時刻は駅順が逆(最後の駅が先頭)で記録されているため、その向きで読む
- `BrunchCoreEkiIndex` を持つ駅は、指された駅と同じ分岐駅として1つにまとめる。リストの隣同士は基本的につながるが、分岐駅とその相手の間にある側の隣接は実際の線路ではないので外す
- 本線は、下り向きにたどれる最も長い経路を選ぶ
- 通過駅の時刻はファイルに無いため、通過列車は駅間の補間で位置を求める

## 開発メモ

ビルド不要の単一ファイル(`index.html`)です。外部依存は Google Fonts のみ(読み込めなくてもフォールバックで動作)。

## 注意

ダイヤのファイルは含めていません。自分のファイルを読み込んで使ってください。時刻表に基づく計算上の位置であり、実際の運行とは異なります。
